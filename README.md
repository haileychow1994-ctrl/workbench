# 小周工作台

专利律师的工具。帮你管案子、管任务、管期限。

数据在浏览器里。不联网也能用。

在线用：

https://haileychow1994-ctrl.github.io/workbench/

---

## 能做什么

### 任务看板
- 加任务
- 关联案子
- 设优先级
- 设截止日
- 标状态
- 标卡住原因
- 番茄钟计时
- 自动算今天该干什么、快到期了、等了多久

### 案件库
- 加案子、改案子
- 记案号、专利号、阶段
- 关联案子
- 看进度
- 管文档
- 管证物
- 大事记时间轴

### 智能收件箱
一个入口。扔进来就行。

能上传：
- PDF
- JPG
- PNG

能粘贴：
- 领导消息
- 客户需求
- 技术方案
- 官文
- 期限通知

系统自动看：
- 已有案子？更新。
- 新案子？建一个。
- 咨询？先放待确认。
- 独立任务？直接建。
- 看不懂？问你。

看完弹窗。你核对。确认。写入。

### AI 识别
接 DeepSeek API。从官文里抓：
- 案号
- 专利号
- 案件名
- 文件类型
- 程序类型
- 当事人
- 法定期限
- 口审日期
- 摘要

API Key 只在浏览器里。不上传。

### 日历
- 红色：法定期限
- 橙色：内部截止
- 点日期看当天任务
- 自动同步

### 工作日志
晚上自动生成。今天干了什么。

| 日期 | 客户 | 案号 | 主办 | 干了什么 | 多久 |

能复制。能导出 CSV。

### 数据搬家
数据在浏览器里。换电脑不会自己跟过来。

解决办法：
- 公司电脑：导出
- 家里电脑：导入
- 继续用

支持覆盖导入、合并导入。

---

## 数据在哪

浏览器 `localStorage` 里。

包括：
- 案子
- 任务
- 设置
- 复盘
- 归档

不会自动上传。

清缓存会丢。定期导出备份！

---

## AI 怎么用

先填 DeepSeek API Key。

获取：
https://platform.deepseek.com

只在浏览器本地。不泄露。
