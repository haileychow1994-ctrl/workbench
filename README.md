# 小周工作台

一个面向专利/诉讼律师日常工作的本地化任务与案件管理工具。

它帮助我把案件、任务、期限、文件识别、领导消息、工作日志放在一个页面里管理。  
数据默认保存在浏览器本地，适合个人工作台使用。

## 在线访问

GitHub Pages：

https://haileychow1994-ctrl.github.io/workbench/

## 主要功能

### 1. 任务看板

- 新增任务
- 关联案件
- 设置优先级
- 设置截止日
- 标记任务状态
- 标记卡住原因
- 番茄钟计时
- 自动统计今日待办、临期任务、等待反馈和今日耗时

### 2. 案件库

- 新增/编辑案件
- 记录所内案号、官方案号、专利号、程序阶段
- 支持关联案件
- 展示案件组和全局进展
- 管理关键文档
- 管理证物/实物
- 案件详情抽屉展示“大事记”时间轴

### 3. 智能收件箱

统一处理文件和消息。

可以上传：

- PDF
- JPG
- PNG

也可以粘贴：

- 领导消息
- 客户需求
- 技术方案
- 官文正文
- 期限通知

系统会自动判断内容类型：

- 已有案件更新
- 新案件并提取任务
- 咨询案件 / 待所内立案
- 独立任务
- 未知内容

识别后会弹出确认界面，用户可以修改案件信息和任务字段，再确认写入。

### 4. AI 文件识别

支持通过 DeepSeek API 从官方文件中提取：

- 所内案号
- 官方案号
- 专利号
- 案件名称
- 文件类型
- 程序类型
- 当事人
- 法定期限
- 口审日期
- 摘要信息

> 注意：API Key 只保存在浏览器本地，不会上传到 GitHub。

### 5. 日历视图

- 红色显示法定期限
- 橙色显示内部截止日
- 点击日期查看当天任务
- 任务和案件期限会自动同步到日历

### 6. 工作日志

每天可根据已完成任务自动生成工作日志表格。

表头包括：

| 日期 | 客户/委托人 | 案号/咨询号 | 主办律师 | 工作简述 | 工作时长/H |
| --- | --- | --- | --- | --- | --- |

支持：

- 复制表格
- 导出 CSV

### 7. 数据导入/导出

因为本项目默认使用浏览器 `localStorage` 保存数据，所以不同电脑之间不会自动同步数据。

为了解决多电脑使用问题，系统提供：

- 导出数据
- 导入数据
- 覆盖导入
- 合并导入

推荐使用方式：

1. 公司电脑导出 JSON 备份
2. 家里电脑导入 JSON 备份
3. 继续使用

## 数据存储说明

本项目是纯前端应用。

数据保存在浏览器本地：

```text
localStorage
```

包括：

- 案件数据
- 任务数据
- 设置
- 今日复盘
- 复盘归档

不会自动上传到服务器。

如果清空浏览器缓存，数据可能丢失。  
请定期使用“导出数据”备份。

## AI 使用说明

使用 AI 功能前，需要填写 DeepSeek API Key。

获取地址：

https://platform.deepseek.com

API Key 只保存在当前浏览器本地。

```bash

```text

```

## 适用场景

适合个人律师或小团队管理：

- 专利无效案件
- 专利侵权诉讼
- 行政诉讼
- 官文期限
- 客户咨询
- 领导交办任务
- 每日工作日志

## 注意事项

- 本项目不是律所正式案件管理系统
- 不建议存放高度敏感信息

- 法定期限请以官方文件和人工复核为准

## 设计风格

系统提示采用简短、直接的 Rocky 风格：

```text
收到了!
看完了。核对?
没找到。
先加一个?
坏了。重试?
```

目标是减少噪音，让用户快速处理事务。
